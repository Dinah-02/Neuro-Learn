# Neuro-Learn 🧠

Neuro-Learn is an AI-powered learning platform designed to help developers stay updated with technology trends, explore developer news, and discover relevant learning opportunities.

## Features

- **Developer News:** Explore technology news and updates.
- **GitHub Intelligence:** Analyze GitHub activity and discover development trends.
- **Learning Insights:** Organize technology insights to support continuous learning.
- **Modular Architecture:** Separate application components for easier development and maintenance.

## Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Package Management:** npm / pnpm / Bun

## Getting Started

### Prerequisites

- Node.js
- A package manager such as npm, pnpm, or Bun

### Installation

Clone the repository:

```bash
git clone https://github.com/Dinah-02/Neuro-Learn.git
cd Neuro-Learn
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
